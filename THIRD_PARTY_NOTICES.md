# Third-party notices

PramanaSutra AI v0.3.2 has **no runtime dependencies** and bundles no third-party source code, fonts, images or data.

- Runtime: the Node.js standard library only (provided by your Node.js installation).
- Documentation HTML is generated from project Markdown by `scripts/build-docs.mjs`. CSS and the small page script are original files by the project author (`scripts/docs-site.css`, `scripts/docs-site.js`). Pages use system fonts. They do not load a CDN, a font host, or a chart library. The architecture figure is an inline SVG.
- Standards and products named in documentation (WCAG, OWASP, SLSA, Claude Code, Cursor, Codex, Copilot, Gemini CLI and others) are referenced for compatibility or inspiration only. Their names belong to their owners.
