CLI reference

Every pramanasutra command, flag, exit code, policy key and environment fact.

Version 0.2.0 · Source: docs/handbook/06-cli-reference.md

Binary: pramanasutra (packages/cli/bin/pramanasutra.mjs). Without installation use npx github:shahvatsalofficial/pramanasutra-ai <command> or node packages/cli/bin/pramanasutra.mjs <command>.

Commands#

CommandPurpose
helpPrint usage
doctor [--json]Check Node version and platform; confirms no AI key is needed
agents list [--json]List the 17 bundled skills
scan --path <dir> [--out <dir>] [--no-report] [--json]Static QA audit and reports
release-check --path <dir> [--evidence <file>] [--policy <file>] [--out <dir>] [--no-report] [--json]Scan plus release gate
verify --evidence <file> [--json]Validate an evidence file
init --ide <name> --target <dir> [--force]Copy skills into a project

Flags#

FlagApplies toMeaning
--pathscan, release-checkDirectory to inspect. Must be a real directory
--outscan, release-checkReport directory (default ./pramanasutra-reports)
--no-reportscan, release-checkDo not write report files
--evidencerelease-check, verifyTest-evidence JSON file
--policyrelease-checkPolicy JSON file
--ideinitclaude, cursor, codex, gemini, copilot, generic, all
--targetinitExisting directory to install into
--forceinitOverwrite existing skill directories
--jsonmostPrint JSON instead of text

scan rejects --evidence and --policy with exit 1 because they only affect the gate.

Exit codes#

CodeMeaning
0Success or READY_FOR_HUMAN_APPROVAL
1Invalid input or error
2NO_GO (release-check)
3REVIEW_REQUIRED (release-check)

scan exits 0 even when it has findings. Use release-check to gate a build.

Skill install locations#

--ideDirectory under --target
claude.claude/skills/
cursor.cursor/skills/
codex.agents/skills/
gemini.gemini/skills/
copilot.github/skills/
generic.agents/skills/
allall of the above

The installer refuses symlinked destination components, refuses a non-directory target, and never overwrites without --force.

Policy keys#

KeyTypeDefaultMeaning
namestringrecommendedLabel shown in reports
releaseRequiresExecutedEvidencebooleantruePassing evidence needed for ready
blockOnFocusedTestsbooleantrueFocused tests give NO_GO
blockOnSkippedTestsbooleanfalseSkipped tests give NO_GO
requireCibooleantrueMissing CI means review required
requireLicensebooleantrueMissing license means review required
requireTestsbooleantrueNo test files means review required
schemaVersion"1.0.0"Accepted for documentation
allowAutomatedDeploymentmust be falseCannot be weakened
manualApprovalsRequiredmust be trueCannot be weakened

Any other key, or a wrong type, makes the command fail with exit 1.

Examples#

pramanasutra scan --path . --out reports/qa
pramanasutra release-check --path . --evidence ci-evidence.json --policy policies/strict.json
pramanasutra verify --evidence ci-evidence.json --json
pramanasutra init --ide all --target ../my-app

Environment#

No environment variables are read. No files are read outside --path, --evidence, --policy and the bundled skills. No network access.
