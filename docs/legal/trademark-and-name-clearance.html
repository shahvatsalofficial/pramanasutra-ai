Trademark and name clearance

Status of the PramanaSutra name, what has and has not been checked, and a brief for a lawyer.

Version 0.2.0 · Source: docs/legal/trademark-and-name-clearance.md

Status#

The names PramanaSutra and PramanaSutra AI are used by the creator, Vatsal Shah, as project names. They are not registered and not cleared. No search of trademark registers, domain registries or package registries has been completed for this project.

Third-party marks#

Claude, Claude Code, Anthropic, Cursor, OpenAI, Codex, GitHub, GitHub Copilot, Gemini and Google belong to their owners. They appear only to describe compatibility (nominative use). No logo of any of them is used. No endorsement is implied.

Brief for a lawyer#

  1. Is "PramanaSutra" likely to conflict with existing marks in software and quality-assurance classes (Nice 9, 42)?
  2. Are the Sanskrit-derived words descriptive or generic in any target market?
  3. Does the wording in README and docs avoid implying certification or affiliation?
  4. Is Apache-2.0 with the current NOTICE appropriate and sufficient for the intended distribution?
  5. Are the disclaimers adequate for QA and release-decision tooling?

Until cleared#

Do not claim the name is registered. Do not use the registered-trademark symbol. Be ready to rename if a conflict appears: the name is isolated to documentation, package.json and file names.
