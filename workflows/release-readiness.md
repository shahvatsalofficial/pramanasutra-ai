# Release Readiness

**Goal:** Apply a conservative gate and identify unknowns.

1. Confirm authorized scope, environment and data-handling expectations.
2. Gather facts, existing tests and execution evidence without inventing it.
3. Recommend checks and obtain explicit approval before running code, making changes or contacting external systems.
4. Record executed vs not-run checks, observations, failures and limitations.
5. Produce evidence-backed recommendations and hand back any release decision to a human.
