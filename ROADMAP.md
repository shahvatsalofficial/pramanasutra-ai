# Roadmap

- v0.1 starter: local static audit, conservative release gate, portable skills, installers, reports, own test suite.
- Next: permissioned test runner, evidence ingestion and genuine framework adapters.
- Next: reliable JUnit/SARIF/coverage ingest, change impact, flaky test diagnosis and policies.
- Later: browser visual/accessibility/performance suites, mobile/TV/device labs, release pipeline integrations.
- Later: optional self-hosted isolated server, approved API/local model adapters, optional dashboard.

No planned feature should be advertised as already implemented.
