# Contributing

Thank you for helping improve PramanaSutra AI. Open an issue for larger changes, propose a small testable improvement, and add tests for behavior changes. Run `npm test` and `node packages/cli/bin/pramanasutra.mjs doctor` before submitting. New Agent Skills need unique frontmatter, explicit safety boundaries, reproducible outputs, and limitations. New adapters must document supported host versions and install/uninstall behavior. Do not submit proprietary assets, passwords or real customer data. License contributions under the project license.
