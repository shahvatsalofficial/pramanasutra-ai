Frequently asked questions

What is PramanaSutra AI?

An open-source AI QA and release-readiness agent: 17 portable Agent Skills plus a deterministic offline CLI that audits test hygiene, ingests test-run evidence and issues a conservative release gate (NO_GO, REVIEW_REQUIRED or READY_FOR_HUMAN_APPROVAL).

Does it run my tests?

No. The CLI never executes the target project's tests or scripts. It reads test-run evidence you supply from your own runner or CI. Test execution is on the roadmap and will need explicit approval.

Do I need an API key?

No. The CLI is offline. Inside a supported AI IDE the skills use that IDE's own model.

Can it approve a release?

No. The best outcome is READY_FOR_HUMAN_APPROVAL, which always requires a person to approve. automatedDeploymentAuthorized is always false.

Does it certify quality, security or compliance?

No. Reports are review aids, not certifications or legal advice.
