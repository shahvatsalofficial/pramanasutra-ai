## Brief for a lawyer

1. Is "PramanaSutra" likely to conflict with existing marks in software and quality-assurance classes (Nice 9, 42)?
2. Are the Sanskrit-derived words descriptive or generic in any target market?
3. Does the wording in README and docs avoid implying certification or affiliation?
4. Is Apache-2.0 with the current `NOTICE` appropriate and sufficient for the intended distribution?
5. Are the disclaimers adequate for QA and release-decision tooling?
